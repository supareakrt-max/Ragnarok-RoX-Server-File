# วิธีใช้ระบบ AI (`@ai`) — Ro-X

แบ่งเป็น 2 ส่วน
- **ส่วน A — สำหรับแอดมิน:** ติดตั้ง, คอมไพล์, ตั้งราคา, แก้ปัญหา
- **ส่วน B — สำหรับผู้เล่น:** วิธีเปิดใช้, ตั้งค่า, ตัวอย่าง (ก๊อปไปลงเว็บ/Discord ได้)

# ส่วน A — สำหรับแอดมิน

## A1. ติดตั้ง (ทำครั้งเดียว)

### ขั้นที่ 1 — สำรองของเดิม
```
Server\map-server.exe  →  ก๊อปไปไว้  Server\backup_before_ai\map-server.exe
```

### ขั้นที่ 2 — ใส่ไฟล์ source
1. ก๊อป `ai_system\src\custom\ai_player.inc` → `Server\src\custom\ai_player.inc`
2. เปิด `Server\src\custom\script.inc` ด้วย Notepad แล้ว **ต่อท้ายไฟล์**:
   ```cpp
   // Ro-X: Player AI (@ai)
   #include <custom/ai_player.inc>
   ```
3. เปิด `Server\src\custom\script_def.inc` แล้ว **ต่อท้ายไฟล์**:
   ```cpp
   // Ro-X: Player AI (@ai)
   BUILDIN_DEF(ai_on, "?"),
   BUILDIN_DEF(ai_off, "?"),
   BUILDIN_DEF(ai_status, "?"),
   BUILDIN_DEF(ai_maplist, "?"),
   BUILDIN_DEF(ai_skilltype, "i"),
   BUILDIN_DEF(ai_skillname, "i"),
   ```
> ห้ามใส่ซ้ำ ถ้าเคยใส่บรรทัดไหนไปแล้วให้ข้าม

### ขั้นที่ 3 — คอมไพล์ map-server
**แบบ Visual Studio 2022**
1. เปิด `Server\rAthena.sln`
2. แถบด้านบนเลือก **Release** และ **Win32** (ห้ามเลือก x64 — dll ที่ใช้อยู่เป็น 32-bit)
3. ช่อง Solution Explorer → คลิกขวา **map-server** → **Build**
4. รอจนขึ้น `Build succeeded` → ได้ `map-server.exe` ใหม่ในโฟลเดอร์ Server

**แบบให้ Claude คอมไพล์ให้**
- ส่งโฟลเดอร์ `Server\src\custom\` (หลังทำขั้นที่ 2) มา → ได้ `map-server.exe` กลับไป

### ขั้นที่ 4 — ใส่ NPC เมนู
1. ก๊อป `ai_system\npc\ai_menu.txt` → `Server\npc\Npc RoX\ai_menu.txt`
2. เปิด `Server\npc\scripts_custom.conf` หาส่วน `===== Npc RoX =====` แล้วเพิ่มบรรทัด:
   ```
   npc: npc/Npc RoX/ai_menu.txt
   ```
> ⚠ ต้องใช้คู่กับ `map-server.exe` ตัวใหม่เท่านั้น — exe เก่าจะขึ้น error `calling undeclared function` ที่ `ai_menu.txt`

### ขั้นที่ 5 — รีสตาร์ทเซิร์ฟ
ปิด/เปิดเซิร์ฟทั้งหมดผ่าน RO_Manager → ดูหน้าต่าง map-server ว่าไม่มี error สีแดงเกี่ยวกับ `ai_menu.txt`

### ขั้นที่ 6 — ทดสอบด้วยไอดี GM
1. ล็อกอินไอดี GM (เลเวล 99) ออกไปแมพนอกเมือง เช่น `@warp prt_fild08`
2. พิมพ์ `@ai` → **ซื้อเวลา AI** → **[GM] เติมฟรี 24 ชม.**
3. กลับเมนู → **เปิด AI** → ปิดหน้าต่าง → ตัวละครควรเดินไปตีมอนเอง
4. ทดสอบตามเช็กลิสต์ใน `README.md`

## A2. ตั้งราคาเวลา AI

เปิด `Server\npc\Npc RoX\ai_menu.txt` หาส่วน `OnInit`:

```
	.buy_hours = 4;          // ซื้อครั้งละกี่ชั่วโมง
	.buy_zeny = 1000000;     // ราคา Zeny
	.buy_cash = 2;           // ราคา Cash Point
	.max_hours = 720;        // สะสมเวลาได้สูงสุดกี่ชั่วโมง
	.gm_level = 99;          // GM เลเวลนี้ขึ้นไปเติมฟรีได้
```
แก้แล้วเซฟ (ไฟล์เป็น **TIS-620** — ใช้ Notepad++ ตั้ง Encoding เป็น Thai/TIS-620 ก่อนแก้) → พิมพ์ `@reloadscript` ในเกม **ไม่ต้องคอมไพล์ใหม่**

## A3. จัดการเวลา AI ของผู้เล่น (phpMyAdmin)

เวลาเก็บเป็นวินาทีในตาราง **`acc_reg_num`** (key = `#AI_TIME`)

| ต้องการ | SQL |
|---|---|
| ดูเวลาของทุกไอดี | ``SELECT account_id, value/3600 AS hours FROM acc_reg_num WHERE `key` = '#AI_TIME';`` |
| เติม 4 ชม. ให้ไอดี 2000001 | `INSERT INTO acc_reg_num VALUES (2000001,'#AI_TIME',0,14400) ON DUPLICATE KEY UPDATE value = value + 14400;` |
| ดูประวัติการซื้อ | `SELECT * FROM rathena_logs.npclog WHERE mes LIKE 'AI time%';` |

> แก้ผ่าน SQL ต้องให้ผู้เล่น **ออฟไลน์** ก่อน ไม่งั้นค่าในเกมจะเขียนทับ

## A4. ถอนออก
1. ลบบรรทัด `npc: npc/Npc RoX/ai_menu.txt` ใน `scripts_custom.conf`
2. เอา `backup_before_ai\map-server.exe` กลับมาทับ
3. รีสตาร์ทเซิร์ฟ

## A5. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| map-server ขึ้น `calling undeclared function` ที่ ai_menu.txt | ยังใช้ exe เก่า → คอมไพล์ใหม่ / เช็กขั้นที่ 2 |
| คอมไพล์ error `ai_player.inc: No such file` | ลืมก๊อป `ai_player.inc` ไป `src\custom\` |
| คอมไพล์ error `redefinition of buildin_ai_on` | ใส่ `#include` ใน script.inc ซ้ำ 2 ครั้ง |
| ข้อความไทยในเมนูเป็นภาษาต่างดาว | `ai_menu.txt` ถูกเซฟเป็น UTF-8 → เซฟใหม่เป็น TIS-620 |
| `@ai` ไม่มีอะไรขึ้น | NPC ไม่ได้โหลด → เช็ก scripts_custom.conf |
| เปิด AI แล้วยืนนิ่ง | ไม่มีมอนในรัศมี / ตั้ง "ตีเฉพาะที่ติ๊ก" แต่ไม่ได้ติ๊กมอน / ไม่มี Fly Wing |

# ส่วน B — สำหรับผู้เล่น

## B1. เริ่มใช้ใน 3 ขั้น

1. **ซื้อเวลา AI** — พิมพ์ `@ai` → **ซื้อเวลา AI**
   - 4 ชั่วโมง = **1,000,000 Zeny** หรือ **2 Cash Point**
   - เวลาเป็นของไอดี ใช้ได้ทุกตัวละคร นับเฉพาะตอนเปิด AI
2. **ตั้งค่า** — ตามหัวข้อ B3 / B4 ด้านล่าง (ไม่ตั้งก็ได้ AI จะตีธรรมดา)
3. **เปิด AI** — ออกไปแมพนอกเมือง → `@ai` → **เปิด AI** → **ปิดหน้าต่าง** (AI เริ่มทำงานเมื่อปิดหน้าต่าง)

## B2. คำสั่ง

| คำสั่ง | ผล |
|---|---|
| `@ai` | เปิดหน้าต่างตั้งค่า |
| `@ai on` | เปิด AI ทันที |
| `@ai off` | ปิด AI ทันที |

## B3. ตั้งค่าโหมดฟาร์มมอน

| เมนู | ตั้งอะไร | แนะนำ |
|---|---|---|
| **การโจมตี / เลือกมอน** | รัศมีหามอน (3–14 ช่อง) | 9–12 |
| | ตี / ไม่ตีบอส-MVP | ไม่ตี ถ้าตัวยังอ่อน |
| | **เลือกมอนที่จะตี (แมพนี้)** — กดชื่อมอนเพื่อติ๊ก `[/]` | ดูหัวข้อ B5 |
| **สกิลโจมตี** | เลือกได้ 5 สกิล ใช้ตามลำดับบนลงล่าง | ใส่สกิลแรงสุดไว้บน |
| | ใช้สกิลเมื่อ SP ≥ __% | 20–30% จะได้เหลือ SP ไว้บัฟ |
| **บัฟตัวเอง** | 6 สกิล ร่ายใหม่เองเมื่อหมด | เช่น Endure, Two-Hand Quicken |
| **ยา HP / SP** | เลือกยาจากกระเป๋า + กินเมื่อต่ำกว่า __% | HP 50–60%, SP 20–30% |
| **เก็บของ** | ไม่เก็บ / เก็บทุกชิ้น / เก็บเฉพาะที่เลือก | ฟาร์มการ์ด → เก็บเฉพาะการ์ด |
| **กลับเมือง / ปีกแมลงวัน** | กลับเมืองเมื่อ HP < __% / ยาหมด / น้ำหนัก ≥ __% | ต้องมี **Butterfly Wing** ในกระเป๋า |
| | ใช้ Fly Wing เมื่อหามอนไม่เจอ __ วินาที | 10–20 วิ, ต้องมี **Fly Wing** |

## B4. ตั้งค่าโหมดซัพพอร์ตเดินตาม (สาย Acolyte / Priest / ฯลฯ)

1. **เข้าปาร์ตี้** เดียวกับคนที่จะตามก่อน
2. `@ai` → **เปลี่ยนโหมด** จนเป็น "ซัพพอร์ตเดินตาม"
3. `@ai` → **ตั้งค่าซัพพอร์ต**:

| เมนู | ตั้งอะไร | แนะนำ |
|---|---|---|
| เลือกคนที่จะตาม | เลือกจากรายชื่อในปาร์ตี้ | |
| ตั้งระยะตาม | 1–10 ช่อง | 2–3 |
| เลือกสกิลฮีล | เช่น Heal | |
| ตั้ง % HP ที่จะฮีล | ฮีลคนที่ HP ต่ำกว่านี้ (คนต่ำสุดก่อน) | 70–80% |
| บัฟปาร์ตี้ | 6 สกิล เช่น Blessing, Increase AGI, Angelus | |
| ชุบชีวิต | เปิด/ปิด (ต้องมีสกิล Resurrection + Blue Gemstone) | |

4. ตั้ง **ยา SP** ใน "ยา HP / SP" ด้วย จะได้ฮีลได้นาน
5. **เปิด AI** — ตัวละครจะเดินตาม, ฮีล, บัฟทุกคนในปาร์ตี้ที่อยู่ใกล้ ๆ

> โหมดซัพพอร์ตเข้าเมืองได้ แต่ **วาร์ปตามไม่ได้** — ถ้าคนที่ตามวาร์ปไปแมพอื่น ต้องวาร์ปตามเองแล้วเปิด AI ใหม่

## B5. เลือกมอนที่จะตี (ติ๊ก)

`@ai` → **การโจมตี / เลือกมอน** → **เลือกมอนที่จะตี (แมพนี้)**

```
แมพ: prt_fild08  โหมด: ตีเฉพาะที่ติ๊ก
> เปลี่ยนโหมด
> ติ๊กทั้งหมด
> เอาออกทั้งหมด
> [/] Poring (70 ตัว)
> [  ] Lunatic (40 ตัว)
> [  ] Pupa (20 ตัว)
> [  ] Drops (10 ตัว)
> กลับ
```

| โหมด | ใช้เมื่อ |
|---|---|
| ตีทุกตัว | ปั๊มเลเวลทั่วไป (ติ๊กไว้ก็ไม่มีผล) |
| ตีเฉพาะที่ติ๊ก | ฟาร์มการ์ด / ของจากมอนตัวเดียว |
| ตีทุกตัว ยกเว้นที่ติ๊ก | เลี่ยงมอนตีแรง / มอนที่มาเป็นฝูง |

- จำแยกแต่ละแมพ ย้ายแมพแล้วกลับมาก็ยังอยู่
- มอนที่ **กำลังตีเรา** AI จะตีกลับเสมอ ไม่ว่าจะติ๊กหรือไม่

## B6. AI จะหยุดเองเมื่อ
- ตัวละครตาย
- ย้ายแมพ / เข้าเมือง (โหมดฟาร์ม)
- น้ำหนัก ≥ 90%
- กลับเมืองด้วย Butterfly Wing ตามที่ตั้งไว้
- หมดเวลา AI (เหลือ 10 นาทีจะเตือนก่อน)
- ออกจากเกม
- โหมดซัพพอร์ต: คนที่ตามไม่อยู่ในแมพเกิน 60 วินาที

ระหว่างคุย NPC / เปิดร้าน / เทรด / นั่ง — AI จะรอ ไม่ทำอะไร

## B7. ตัวอย่างการตั้งค่า

**Swordman/Knight ปั๊มเลเวล**
- รัศมี 12, ไม่ตีบอส
- สกิลโจมตี: Bash, ใช้เมื่อ SP ≥ 20%
- บัฟตัวเอง: Endure
- ยา HP: Red Potion เมื่อ HP < 50%
- เก็บของ: เก็บทุกชิ้น
- กลับเมือง: ยา HP หมด + น้ำหนัก ≥ 80%
- Fly Wing: 15 วินาที

**Priest ตามเพื่อน**
- โหมด: ซัพพอร์ตเดินตาม, ระยะ 2
- ฮีล: Heal เมื่อ HP < 75%
- บัฟปาร์ตี้: Blessing, Increase AGI, Angelus
- ชุบชีวิต: เปิด
- ยา SP: Blue Potion เมื่อ SP < 20%

## B8. คำถามที่พบบ่อย

**ปิดเกมแล้ว AI ยังทำงานไหม?** — ไม่ AI ปิดทันทีที่ออกเกม
**เวลาหักตอนไหน?** — เฉพาะตอน AI เปิดอยู่ ปิด AI เวลาก็หยุด
**ซื้อเวลาแล้วใช้ตัวอื่นได้ไหม?** — ได้ เวลาเป็นของไอดี
**ใช้ในเมืองได้ไหม?** — โหมดฟาร์มไม่ได้, โหมดซัพพอร์ตได้
**ทำไม AI ยืนนิ่ง?** — ไม่มีมอนในรัศมี / ตั้งตีเฉพาะที่ติ๊กแต่ไม่ได้ติ๊ก / มอนที่ติ๊กตายหมด → ตั้ง Fly Wing ไว้ช่วย
