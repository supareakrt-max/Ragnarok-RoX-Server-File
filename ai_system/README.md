# Ro-X Player AI (`@ai`) — ขั้นที่ 1–6

ระบบ AI ให้ผู้เล่น: พิมพ์ `@ai` เปิดหน้าต่างตั้งค่า แล้วตัวละครจะทำงานเอง 2 โหมด
- **ฟาร์มมอน**: หามอน → เดินไปตี → ใช้สกิล/บัฟ → กินยา → เก็บของ → กลับเมือง
- **ซัพพอร์ตเดินตาม**: เดินตามเพื่อนในปาร์ตี้ → ฮีลคนเลือดน้อยสุด → บัฟปาร์ตี้ → ชุบชีวิต

โหมดฟาร์มต้องมี **เวลา AI** (ต่อไอดี): ซื้อ 4 ชม. = 1,000,000 Zeny หรือ 2 Cash Point นับถอยหลังเฉพาะตอน AI ทำงาน — **โหมดซัพพอร์ตใช้ฟรี**

เปิดเมนูได้ 2 ทาง: พิมพ์ `@ai` หรือ **กดใช้ไอเทม AI Controller (ID 60400)** — ไอเทมไม่หาย, ทิ้ง/ขาย/ใส่รถเข็น/ส่งเมลไม่ได้

**AI ทำงานต่อเนื่องข้ามแมพ** — วาร์ป/เดินผ่านประตูแล้วไม่ปิด, โหมดฟาร์มพักในเมืองแล้วทำต่อเมื่อออก, ซัพพอร์ตเดินตามผ่านประตูวาร์ป

> **วิธีใช้ทีละขั้น (แอดมิน + ผู้เล่น) ดูที่ `HOW_TO_USE.md`**

> โฟลเดอร์นี้แยกไว้ต่างหาก **ยังไม่ได้ใส่ใน `src/` และ `npc/` ของเซิร์ฟจริง** — ต้องคอมไพล์ map-server ใหม่ก่อนใช้

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ไปไว้ที่ | หน้าที่ |
|---|---|---|
| `src/custom/ai_player.inc` | `Server\src\custom\` | ตัว AI (C++) + คำสั่งสคริปต์ |
| `src/custom/script.inc` | ต่อท้าย `Server\src\custom\script.inc` | `#include` ให้ script.cpp ดึง ai_player.inc เข้าไป |
| `src/custom/script_def.inc` | ต่อท้าย `Server\src\custom\script_def.inc` | ลงทะเบียนคำสั่งสคริปต์ 6 ตัว |
| `npc/ai_menu.txt` | `Server\npc\Npc RoX\` | คำสั่ง `@ai` + หน้าต่างเมนู + แจกไอเทม (TIS-620) |
| `db/item_db_ai.yml` | ต่อท้าย `Body:` ใน `Server\db\import\item_db.yml` | ไอเทม AI Controller (ID 60400) |

ใช้ช่อง `src/custom/` ที่ rAthena เตรียมไว้ → **ไม่ต้องแก้ไฟล์ .cpp ของเดิมเลย** และไม่ต้องเพิ่มไฟล์ใน rAthena.sln / CMakeLists

## ขั้นตอนติดตั้ง

1. **สำรอง** `Server\map-server.exe` ไปไว้ `Server\backup_before_ai\`
2. ก๊อป `ai_system\src\custom\ai_player.inc` → `Server\src\custom\ai_player.inc`
3. เปิด `Server\src\custom\script.inc` แล้ว**ต่อท้าย**:
   ```cpp
   // Ro-X: Player AI (@ai)
   #include <custom/ai_player.inc>
   ```
4. เปิด `Server\src\custom\script_def.inc` แล้ว**ต่อท้าย**:
   ```cpp
   // Ro-X: Player AI (@ai)
   BUILDIN_DEF(ai_on, "?"),
   BUILDIN_DEF(ai_off, "?"),
   BUILDIN_DEF(ai_status, "?"),
   BUILDIN_DEF(ai_maplist, "?"),
   BUILDIN_DEF(ai_skilltype, "i"),
   BUILDIN_DEF(ai_skillname, "i"),
   ```
   (ถ้าไฟล์เดิมมีแต่คอมเมนต์ จะก๊อปไฟล์จากโฟลเดอร์นี้ไปทับทั้งไฟล์ก็ได้ — ขั้นที่ 5–6 ไม่มีคำสั่งใหม่)
   ⚠ ถ้าเคยใส่ของขั้นที่ 1 (3 บรรทัด) ไปแล้ว ให้เพิ่มแค่ 3 บรรทัดล่าง
5. **คอมไพล์ map-server** (ตัวเดียวพอ login/char/web ไม่เปลี่ยน)
   - Visual Studio 2022: เปิด `rAthena.sln` → เลือก **Release / Win32 (x86)** → คลิกขวา `map-server` → Build
     (ต้อง x86 ให้ตรงกับ `libmysql.dll`, `pcre8.dll`, `zlib.dll` ที่ใช้อยู่)
   - หรือส่งโฟลเดอร์ `src\custom` ให้ Claude คอมไพล์ด้วย MinGW แบบเดิม
6. **ไอเทม AI Controller:** เปิด `Server\db\import\item_db.yml` แล้วก๊อปส่วน `- Id: 60400 ...` จาก `ai_system\db\item_db_ai.yml` ไปต่อท้ายใต้ `Body:`
   (ถ้าในไฟล์ยังไม่มี `Body:` ให้เพิ่มบรรทัด `Body:` ก่อน, ถ้า ID 60400 ชนให้เปลี่ยนทั้งในไฟล์นี้และ `.item_id` ใน ai_menu.txt)
7. ก๊อป `ai_system\npc\ai_menu.txt` → `Server\npc\Npc RoX\ai_menu.txt`
   แล้วเพิ่มบรรทัดนี้ใน `Server\npc\scripts_custom.conf` ส่วน `===== Npc RoX =====`:
   ```
   npc: npc/Npc RoX/ai_menu.txt
   ```
   ⚠ ทำข้อ 7 **หลัง** ได้ exe ใหม่แล้วเท่านั้น — exe เก่าไม่รู้จัก `ai_on` จะ error ตอนโหลด NPC
8. รีสตาร์ทเซิร์ฟทั้งหมด

| กลับเมือง / ปีกแมลงวัน | กลับเมื่อ HP < __% / ยา HP หมด / ยา SP หมด / น้ำหนัก ≥ __%, ใช้ Fly Wing เมื่อหามอนไม่เจอ __ วินาที |

### เวลาใช้งาน AI
- เก็บใน `#AI_TIME` (วินาที, ตัวแปรไอดี → ตาราง `acc_reg_num`) ใช้ร่วมกันทุกตัวละครในไอดี
- นับถอยหลังเฉพาะตอน AI เปิดอยู่ใน **โหมดฟาร์ม** (ทุก 1 วิ), เหลือ 10 นาทีขึ้นเตือน, หมดแล้ว AI ปิดเองพร้อมข้อความ
- **โหมดซัพพอร์ต ฟรี** ไม่หักเวลา, เปิดได้แม้เวลาเป็น 0 (เปลี่ยนเป็นโหมดฟาร์มตอนไม่มีเวลา → AI ปิด)
- แก้ราคา/จำนวนชั่วโมงได้ที่ `OnInit` ใน `ai_menu.txt` (`.buy_hours`, `.buy_zeny`, `.buy_cash`, `.max_hours`, `.gm_level`)
- ทุกการซื้อบันทึกใน log (`logmes` → ตาราง `npclog`)

### โหมดซัพพอร์ตเดินตาม
- ต้องอยู่ปาร์ตี้เดียวกับคนที่จะตาม, เลือกคนที่ตามใน "ตั้งค่าซัพพอร์ต"
- ทุก 0.3 วิ ทำตามลำดับ: ชุบชีวิตคนที่ตาย (ถ้าเปิด + มีสกิล Resurrection) → ฮีลคนที่ HP% ต่ำสุด (ต่ำกว่าที่ตั้ง) → บัฟปาร์ตี้ที่หมด → เดินตาม
- ดูแล: คนที่ตาม + สมาชิกปาร์ตี้ในแมพเดียวกันในระยะ 14 ช่อง + ตัวเอง
- คนที่ตามไกลเกินเดินรวดเดียว → เดินเข้าหาทีละช่วง
- บัฟปาร์ตี้รวมสกิลร่ายใส่ตัวที่มีผลทั้งปาร์ตี้ได้: **Magnificat, Gloria**, Angelus — ร่ายใหม่เมื่อมีสมาชิกคนไหนไม่มีบัฟ
- เข้าเมืองได้ (โหมดฟาร์มพักในเมือง), ไม่ตีมอน
- **คนที่ตามเดินเข้าประตูวาร์ป → เดินตามเข้าประตูเดียวกัน** ไปแมพใหม่แล้วตามต่อ
- คนที่ตามวาร์ปด้วยวิธีอื่น (ปีก/NPC/ออฟไลน์) → ขึ้นข้อความ "รอคนที่ตาม" แล้ว **รอ (AI ไม่ปิด)** กลับมาแมพเดียวกันเมื่อไหร่ก็ตามต่อ
- ตาย / น้ำหนักเกิน → รอ (ให้คนชุบ / ลดของ) AI ไม่ปิด

### เลือกมอนในแมพ
- รายชื่อมาจากมอนที่มีชีวิตอยู่ในแมพตอนนี้ พร้อมจำนวน และป้าย [บอส] / [MVP]
- กดชื่อมอนเพื่อสลับ `[/]` (ติ๊ก) กับ `[  ]`, มีปุ่ม ติ๊กทั้งหมด / เอาออกทั้งหมด
- โหมด: **ตีทุกตัว** / **ตีเฉพาะที่ติ๊ก** / **ตีทุกตัว ยกเว้นที่ติ๊ก**
- จำแยกตามแมพ (`AI_MM_<แมพ>`, `AI_ML_<แมพ>$`) แก้ระหว่าง AI ทำงานได้ มีผลทันที
- มอนที่กำลังตีเราอยู่ **ตีกลับเสมอ** ไม่ว่าจะติ๊กหรือไม่ (กันตาย)

### พฤติกรรม AI
- ค่าตั้งทั้งหมดจำไว้กับตัวละคร แต่ **AI ปิดเมื่อออกเกม**
- **ย้ายแมพ (วาร์ป / ประตู / @warp) AI ทำงานต่อ** — ล้างเป้าหมายเดิม แล้วใช้ค่าเลือกมอนของแมพใหม่
- โหมดฟาร์มเข้าเมือง → ขึ้นข้อความ "พักในเมือง" แล้วรอ ออกจากเมืองเมื่อไหร่ทำงานต่อเอง
- ลำดับการคิด (ทุก 0.3 วิ): เช็กกลับเมือง → กินยา → บัฟ → ตีเป้าเดิม → เก็บของ → หามอนใหม่ → Fly Wing → เดินสุ่ม
- AI **เดินเข้าหามอนเอง** (ไม่พึ่งไคลเอนต์) — ใช้สกิลถ้าพร้อม ไม่งั้นตีธรรมดา
- ไม่แย่งมอนที่ผู้เล่นอื่นกำลังตี, ไม่ตีมอนที่ผู้เล่นเรียกออกมา
- มอนที่เดินไปไม่ถึง / ตีไม่โดนใน 15 วิ → ข้ามไป (จำไว้ 60 วิ)
- กลับเมือง = ใช้ Butterfly Wing 1 อัน วาร์ปไปจุดเซฟ แล้ว AI ปิด
- โหมดฟาร์มหยุดเองพร้อมข้อความ: ตาย / น้ำหนัก ≥ 90% / กลับเมืองด้วยปีก / ต้องกลับเมืองแต่ไม่มีปีก / หมดเวลา AI
- ระหว่างคุย NPC, เปิดร้าน, เทรด, นั่ง, ร่ายสกิล → AI รอ
