# Ro-X Player AI (`@ai`) — ขั้นที่ 1

ระบบ AI ให้ผู้เล่น: พิมพ์ `@ai` เปิดหน้าต่างตั้งค่า, ตัวละครหามอนใกล้สุดแล้วเดินไปตีเอง

> โฟลเดอร์นี้แยกไว้ต่างหาก **ยังไม่ได้ใส่ใน `src/` และ `npc/` ของเซิร์ฟจริง** — ต้องคอมไพล์ map-server ใหม่ก่อนใช้

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ไปไว้ที่ | หน้าที่ |
|---|---|---|
| `src/custom/ai_player.inc` | `Server\src\custom\` | ตัว AI (C++) + คำสั่งสคริปต์ `ai_on` / `ai_off` / `ai_status` |
| `src/custom/script.inc` | ต่อท้าย `Server\src\custom\script.inc` | บรรทัด `#include` ให้ script.cpp ดึง ai_player.inc เข้าไป |
| `src/custom/script_def.inc` | ต่อท้าย `Server\src\custom\script_def.inc` | ลงทะเบียนคำสั่งสคริปต์ 3 ตัว |
| `npc/ai_menu.txt` | `Server\npc\Npc RoX\` | คำสั่ง `@ai` + หน้าต่างเมนู (TIS-620) |

ใช้ช่อง `src/custom/` ที่ rAthena เตรียมไว้ → **ไม่ต้องแก้ไฟล์ .cpp ของเดิมเลย** และไม่ต้องเพิ่มไฟล์ใน rAthena.sln / CMakeLists

## ขั้นตอนติดตั้ง

1. **สำรอง** `Server\map-server.exe` ไปไว้ `Server\backup_before_ai\`
2. ก๊อป `ai_system\src\custom\ai_player.inc` → `Server\src\custom\ai_player.inc`
3. เปิด `Server\src\custom\script.inc` แล้ว**ต่อท้าย**:
   ```cpp
   // Ro-X: Player AI (@ai)
   #include <custom/ai_player.inc>
   ```
4. เปิด `Server\src\custom\script_def.inc` แล้ว**ต่อท้าย**:
   ```cpp
   // Ro-X: Player AI (@ai)
   BUILDIN_DEF(ai_on, "?"),
   BUILDIN_DEF(ai_off, "?"),
   BUILDIN_DEF(ai_status, "?"),
   ```
   (ถ้าไฟล์เดิมมีแต่คอมเมนต์ จะก๊อปไฟล์จากโฟลเดอร์นี้ไปทับทั้งไฟล์ก็ได้)
5. **คอมไพล์ map-server** (ตัวเดียวพอ login/char/web ไม่เปลี่ยน)
   - Visual Studio 2022: เปิด `rAthena.sln` → เลือก **Release / Win32 (x86)** → คลิกขวา `map-server` → Build
     (ต้อง x86 ให้ตรงกับ `libmysql.dll`, `pcre8.dll`, `zlib.dll` ที่ใช้อยู่)
   - หรือส่งโฟลเดอร์ `src\custom` ให้ Claude คอมไพล์ด้วย MinGW แบบเดิม
6. ก๊อป `ai_system\npc\ai_menu.txt` → `Server\npc\Npc RoX\ai_menu.txt`
   แล้วเพิ่มบรรทัดนี้ใน `Server\npc\scripts_custom.conf` ส่วน `===== Npc RoX =====`:
   ```
   npc: npc/Npc RoX/ai_menu.txt
   ```
   ⚠ ทำข้อ 6 **หลัง** ได้ exe ใหม่แล้วเท่านั้น — exe เก่าไม่รู้จัก `ai_on` จะ error ตอนโหลด NPC
7. รีสตาร์ทเซิร์ฟทั้งหมด

## วิธีใช้

| คำสั่ง | ผล |
|---|---|
| `@ai` | เปิดหน้าต่าง: เปิด/ปิด AI, ตั้งรัศมีหามอน (3–14 ช่อง), ตี/ไม่ตีบอส-MVP |
| `@ai on` | เปิด AI ทันที |
| `@ai off` | ปิด AI ทันที |

- ค่าตั้งจำไว้กับตัวละคร (`AI_RANGE`, `AI_NOBOSS`) ล็อกอินใหม่ไม่ต้องตั้งซ้ำ แต่ **AI จะปิดเมื่อออกเกม**
- AI หยุดเองพร้อมข้อความเมื่อ: ตาย / ย้ายแมพ (ใช้ Fly Wing ในแมพเดิมได้) / อยู่ในเมือง / น้ำหนัก ≥ 90%
- ระหว่างคุย NPC, เปิดร้าน, เทรด, นั่ง, ร่ายสกิล → AI รอ ไม่ทำอะไร
- ไม่แย่งมอนที่ผู้เล่นอื่นกำลังตีอยู่, ไม่ตีมอนที่ผู้เล่นเรียกออกมา
- ถ้าตีเป้าหมายไม่โดนเลย 15 วินาที (เดินไปไม่ถึง) จะเปลี่ยนเป้า
- ไม่เจอมอน → เดินสุ่มรอบตัว

## เช็กลิสต์ทดสอบ

- [ ] เซิร์ฟเปิดขึ้น ไม่มี error ของ `ai_menu.txt`
- [ ] `@ai` ขึ้นหน้าต่าง, เปิด AI แล้วปิดหน้าต่าง → ตัวละครเดินไปตีมอน
- [ ] ตั้งรัศมี 3 กับ 14 ต่างกันจริง
- [ ] ตั้ง "ไม่ตีบอส" แล้วไม่ตีบอส/MVP
- [ ] `@ai on` ในเมือง → ขึ้น "ใช้ AI ในเมืองไม่ได้"
- [ ] ตาย / วาร์ปออก / ของเต็ม 90% → AI หยุดพร้อมข้อความ
- [ ] ผู้เล่นอื่นตีมอนอยู่ → AI ไม่ไปแย่ง
- [ ] ออกเกมแล้วเข้าใหม่ → AI ปิดอยู่

## ถอนออก

ลบบรรทัด `ai_menu.txt` จาก scripts_custom.conf แล้วเอา `map-server.exe` จาก `backup_before_ai\` กลับมา
